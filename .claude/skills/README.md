# Skills

Skills importés depuis [mattpocock/skills](https://github.com/mattpocock/skills)
(commit `c55ee46`, version du plugin 1.2.3), licence MIT (voir `LICENSE-mattpocock-skills`).

Seuls les skills publiés dans le plugin officiel (catégories `engineering` et
`productivity`) sont inclus ; les dossiers `in-progress`, `misc` et `deprecated` ne le sont pas.

Première étape recommandée : lancer `/setup-matt-pocock-skills` dans ce dépôt.

Pour mettre à jour : recopier les dossiers depuis le dépôt source.

## Skills du projet (patronage)

- `lire-patronage` : photos du livre → `transcription.md` → `patrons/<patron>.etapes.md`,
  validé question par question avec l'utilisateur.
- `tracer-sm2d` : étapes validées → `.sm2d`, vérifié par `tracer-sm2d/verifier.py`
  (export Seamly en ligne de commande). Pièges Seamly : `tracer-sm2d/SEAMLY.md`.
- Références partagées : `doc/patronage/gestes.md`, `doc/patronage/lexique-mesures.md`.
