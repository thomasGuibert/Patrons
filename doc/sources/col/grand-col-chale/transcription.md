# Grand col châle : transcription du livre

Source : *Le vêtement féminin*, tome 1 (ESMOD Éditions) : chapitre « Les cols / Sleeves »,
p. 196-197 (photos de Thomas, 2026-10-27). Texte français recopié ; colonne anglaise lue en regard.

Comme le col châle classique (`../col-chale-classique/`), mais la parementure est aussi développée.
- JO = 1/2 encolure dos + 0,3 cm ; OP = LB = valeur de parementure à l'épaule.
- La valeur X est redistribuée sur 2 à 3 axes.
