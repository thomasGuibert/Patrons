# Tableau des tailles homme 44 à 54 : transcription

Source : `tableau-tailles-homme.jpg`, envoyée par Thomas le 2026-10-12. Intitulés allemand /
espagnol / japonais recopiés sans les caractères japonais. Unité : cm. « Évolution de taille » =
écart d'une colonne à la suivante (2 points de taille).

Texte au-dessus du tableau : « Ce tableau de mesures du corps est composé en drop - 6 pour une
stature 180 ; c'est-à-dire que l'on considère une conformation normale avec 6 cm de différence
entre le 1/2 tour de poitrine et le 1/2 tour de ceinture pour un homme mesurant 1,80 m. Pour
travailler en drop - 8 ou - 10, il suffit de décaler la prise de mesures. Par exemple, pour un
drop - 10, prendre le tour de poitrine T50 (100 cm) avec le tour de ceinture T40 (80 cm). »
